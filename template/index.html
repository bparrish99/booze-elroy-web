Arcade-perfect Pac-Man

Remembered in this browser. Turn it off again any time, here or by typing NEAT on the title screen.

WHAT IT IS

Booze Elroy plays almost exactly like Pac-Man. With NEAT on, it plays exactly like Pac-Man: The real 1980 arcade machine, down to the frame, and down to the pixel. Every ghost's turn, every change of speed, the little pauses when a ghost is eaten, when the fruit appears and how long it stays, how long the ghosts stay blue and when they flash, deaths, the READY signal, and all the rest.

With Plus Mode on, and Difficulty set to Plus, it plays exactly like Pac-Man Plus, not almost exactly like it.

Everything else is still here. You can change any setting, use the abilities, pick a maze style or a background. The arcade never had those, of course, so "exact" means the most on the Classic Pac-Man settings (or Plus).

WHAT CHANGES

  • Its own leaderboards. NEAT games go on separate NEAT boards. While NEAT is on, the high score, name entry and the Leaderboards page all show those. Turn it off and you're back to the regular boards. NEAT scores never mix with the regular ones.
  • No achievements. Achievements belong to the regular game, so none are earned in a NEAT game.
  • No arenas. An arena game played with NEAT on isn't posted.
  • Replays still work. A NEAT score keeps its replay, and it plays back as NEAT for anyone who watches it, without switching their own NEAT on.

HOW IT CAME ABOUT

Booze Elroy started as one person's passion project: rebuild Pac-Man by hand, as close to the arcade as possible. A celebration of, and a love letter to his favorite arcade game. It got very close, close enough that hardly anyone could ever spot a difference.

Hardly anyone. Its maker still could. So NEAT was built afterwards, with the help of an AI assistant, by running the original arcade program in an emulator side by side with this game, feeding both the same control inputs and comparing them frame by frame until they matched on every level.

The regular game is still the hand-built one, untouched. NEAT is a switch, not a replacement. Like a drink served neat: the real thing, nothing added.

One small difference remains: blue ghosts still pick their random turns with this game's own dice (the arcade machine reads its own program code for that).
